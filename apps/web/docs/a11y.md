# Accessibility audit (§7 / 8_Phase.md §1.2)

Phase 8 a11y pass — documented contrast math, fix inventory, and how the
suite is run.

## How to run

```bash
pnpm --filter web test:a11y   # axe-core (Playwright) + keyboard operability
```

Any `serious` or `critical` axe violation fails the suite. Scanned pages:
`/`, `/rentals`, `/map`, `/property/<slug>`, `/login`, `/register`, `/404`
(missing property), `/forbidden`, `/owner` (logged in).

## Color contrast (§3 tokens on §3 backgrounds)

WCAG 2.1 AA: 4.5:1 for body text, 3:1 for large text (≥18.66px bold or
24px). Ratios computed with the WCAG relative-luminance formula against the
actual `packages/ui/src/tokens.css` values.

| Foreground | Background | Ratio | AA body | AA large |
|---|---|---|---|---|
| `#ffffff` fg | `#080808` bg | 20.0:1 | pass | pass |
| `#ffffff` fg | `#121212` card | 18.7:1 | pass | pass |
| `#FFA31A` primary (§3 yellow) | `#080808` bg | 10.0:1 | pass | pass |
| `#FFA31A` primary | `#121212` card | 9.4:1 | pass | pass |
| `#FFA31A` primary | `#181818` elevated | 8.9:1 | pass | pass |
| `#a1a1a1` fg-secondary | `#080808` bg | 7.8:1 | pass | pass |
| `#a1a1a1` fg-secondary | `#121212` card | 7.3:1 | pass | pass |
| `#858585` fg-muted | `#080808` bg | 5.4:1 | pass | pass |
| `#858585` fg-muted | `#121212` card | 5.1:1 | pass | pass |
| `#000000` on primary button | `#FFA31A` | 10.5:1 | pass | pass |

**§3 yellow on the dark backgrounds passes AA at body size — no token change
needed.** One token was adjusted in Phase 8: `--color-fg-muted` was `#6f6f6f`
(3.99:1 on bg — AA fail); it is now `#858585` (5.4:1). Feedback colors are
used with icon + text pairs and were not part of the body-text path.

## Fix inventory (Phase 8)

- **Muted-text contrast**: `--color-fg-muted` `#6f6f6f` → `#858585` (AA at
  body size; used in 121 places, 82 of them at `text-xs`/`text-sm`).
- **Skip-to-content**: `SkipLink` (`apps/web/src/components/nav/SkipLink.tsx`)
  mounted first in every route-group layout; each `<main>` carries
  `id="main-content"`. First Tab stop, visually hidden until focused.
- **Focus visibility**: global `:focus-visible` outline in
  `apps/web/src/app/globals.css` (brand yellow, 2px, 2px offset) — present
  since Phase 0, re-verified.
- **Icon-only buttons**: every icon-only control carries an `aria-label`
  (gallery arrows/close/lightbox, filter drawer close, sort dropdown,
  favorite, share, notification bell). Decorative SVGs are `aria-hidden`.
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` kills
  animation/transition durations globally (`globals.css`).
- **Touch targets**: primary controls use the 8px-scale paddings that yield
  ≥44px hit areas (bottom-nav items are 56px tall; icon buttons carry ≥p-2
  hit padding).

## Keyboard operability (tested in `e2e/a11y.spec.ts`)

- Tab / Shift+Tab walk every page in DOM order; the skip link is the first
  stop.
- Enter submits the login form from the password field (standard form UX).
- Esc closes the rental-request modal; focus returns to the trigger.
- Arrow keys move through pagination links (`/rentals`).

## Screen-reader smoke (manual)

Manual pass with VoiceOver (macOS, Safari) on `/` and `/property/<slug>`:
landmarks announced (nav/main), headings hierarchical, buttons/links named,
gallery images described. Automated SR testing is impractical for the MVP;
axe covers the machine-checkable half.
